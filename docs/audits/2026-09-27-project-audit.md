# Аудит Burette — 27 сентября 2026

Проверка выполнена в ветке `audit/stability-dependencies`, начиная с
`2089aef63`. Области: desktop/browser-dev, Finder Quick Look, iOS,
локальный и hosted MCP, CLI, вычислительные задачи, зависимости и упаковка.
Семь субагентов проверяли независимые области; интеграция, повторные проверки
и ручные сценарии выполнены основным агентом. Это проверка конкретного набора
сценариев, а не гарантия отсутствия любых ошибок.

## Зависимости

Обновлены или добавлены 91 декларация для 70 уникальных npm-пакетов.
Обновлены `bun.lock`, корневой `Cargo.lock`, генерируемые runtime-ресурсы,
plugin bundle и `vendor-assets.lock.json`. Сверка выполнялась с публичными
реестрами; prerelease не выбирались как стабильные обновления.
Для PR с нативными изменениями версия приложения синхронно поднята до
`2026.9.30` по правилу `scripts/check-release-version.mjs`.

Совместимость зафиксирована явно:

- `cluster.v1` и native MMFF сохраняют научную базу RDKit 2025.03.4.
  Отдельный `rdkit-compute` не подменяет RDKit 2026 для обычного просмотра.
  Проверена паритетность fingerprint на эталонных данных.
- TypeScript 7 выполняет typecheck; `typescript-compiler-api` 6.0.3 сохраняет
  последний JS compiler API для AST-преобразований Ketcher и тестов.
- Uni-Mol 0.1.6 требует NumPy `<2.3`, поэтому model-runtime использует 2.2.6.
  Импорты библиотек и небольшое вычисление на MPS проверены в отдельной среде.
- `js-yaml` 4.3.2 сохраняет совместимость транзитивных потребителей.
- Встроенные xTB/CREST и научные протоколы не переводились на новые методы
  расчёта без проверки научной эквивалентности.

Локальный Bun также обновлён с 1.3.8 до 1.4.2, чтобы команды проекта
работали с TypeScript 7. Для `vp` используется версия из `node_modules/.bin`.

`bun audit --json` не сообщает известных уязвимостей (`{}`). Это относится
к npm-графу; не заменяет аудит произвольного Python/C++ кода или инфраструктуры.

## Границы приёмки

- Общий Rust-прогон пропускает 13 opt-in тестов; один из них затем выполнен
  на реальном Metal. Остальные 12 GPU/corpus/50k-row, remote SSH и
  xyzrender-интеграций не выдаются за успешные проверки.
- Проверка SAR preview import требует отдельного optional окружения и была
  пропущена. Реальные model weights не скачивались, обучающие задачи не запускались.
- Физический iPhone, production deployment, нотариализация, обновление обычного
  установленного приложения через Sparkle и публикация Homebrew не выполнялись.
- Сохраняются предупреждения линтера и сборщика о крупных научных bundles;
  аудит не маскирует их повышением лимитов.
- Визуальная проверка нативных окон ожидает разблокировки Mac; запуск процесса
  Simulator сам по себе не доказывает корректный рендеринг. Для Quick Look есть
  отдельное подтверждение содержимого через native semantic smoke и журналы
  установленного расширения.
