# Compute reliability audit — 2026-10-24

## Scope and evidence

Reviewed desktop calculation inputs, native conformer execution, browser compute
transport, Grid options, result presentation, and compute availability in hosted,
Quick Look and iOS viewers. This is a source and focused regression audit, not
certification of every scientific method or a production release acceptance run.
No installed app, user calculation history, or remote compute configuration was
replaced. No external compute jobs were submitted.

Local action logs confirmed SSH descriptor-handoff failures and failure to open a
successfully computed xTB trajectory. Coordinator history alone did not include
all external-runner and presentation failures.

## Fixes in this patch

| Defect | Change | Evidence |
| --- | --- | --- |
| Browser SMILES generation could publish an SDF without bonds | Build an explicit-H MOL with RDKit and use that same graph for parameter extraction and coordinate output | Regression uses real RDKit and packaged extractor WASM for ethanol, charged amine, chiral alanine and E/Z geometry |
| Browser SDF splitting removed empty molecule title lines | Preserve MOL header lines | Blank-title two-record SDF regression |
| Browser Grid ignored selected embedding and MMFF variants | Forward both options through the document/compute bridge | Grid workflow contract |
| Native optimization assumed every input geometry passed stereo validation | Compute actual stereo flags before final validation | CPU native integration test rejects invalid stereo as a result instead of a protocol mismatch |
| PRISM could compute the original file instead of the displayed derived ensemble | Use document data path for input and atom-count guard; retain source path as provenance | Behavioral test starts with derived XYZ and original MOL paths |
| xTB result-view failure overwrote a successful calculation status | Handle presentation errors separately from calculation errors | Behavioral test retains saved successful result after viewer failure |
| Collapsed viewer grip had oversized chrome and stale tooltip | Reuse compact toolbar styling and state-specific tooltip | Toolbar test and in-app browser inspection |
| First Enter after pointer collapse could be swallowed | Do not suppress keyboard clicks with pointer-only click suppression | Toolbar keyboard regression |
| Quick Look/iOS viewers advertised native commands without handlers | Gate compute on preview-only configurations | Capability regression; native device UI acceptance remains separate |

## Unresolved findings

1. **P2 — Chemical Space preparation appears interrupted after restart.**
   `apps/desktop/src-tauri/src/compute/coordinator.rs:205` returns an embedding
   without finishing the durable preparation job; `compute-cluster.ts` retains
   prepared jobs in a cache and cancels them on eviction. Restart recovery can
   label these as WorkerCrashed. Separate reusable preparation state from a
   completed user-visible calculation.
2. **P2 — Chemical Space requires Metal despite CPU selection.**
   `coordinator.rs:245` dispatches directly to the Metal runtime; the learned
   route also requires it. Make the supported execution policy explicit at the
   control boundary or provide the corresponding CPU implementation.
3. **P2 — browser ensemble settings are not fully honored.**
   `dev_backend.rs` uses a fixed ensemble size of 16; candidate-count and RMSD-cutoff
   settings are not applied by this route. Wire the options through validation and
   execution or omit unsupported controls for this surface.

## Validation

Ten existing focused scripts passed: xTB workflow, browser xTB runtime, conformer
workflow, clustering workflow, semiempirical workflow, standalone conformer Jobs,
widget capability, folding results, SAR analysis, and derived-column computation.
These baseline tests passed before the new regressions and did not detect the
identified defects on their own.

Additional checks cover real RDKit topology/extractor parity, Grid option routing,
scene compute input/result handling, toolbar interactions, and native input-geometry
stereo validation. TypeScript typecheck, Rust formatting and Clippy (`--lib --tests
-- -D warnings`) passed. Independent patch review found no additional actionable
defects. The packaged agent shell rebuilt successfully and its mirror check passed
(36 runtime files, 10 scripts). Eight scene/toolbar tests passed with 31 assertions.
The browser verification server was stopped after inspection.
Full scientific reference corpora, all semiempirical methods,
large-collection performance, remote execution, iOS devices, packaged desktop and
Finder Quick Look remain outside the completed acceptance evidence.


## Follow-up: actual user session and local diagnostics

The action journal correlated failed xTB/CREST submissions with SSH descriptor
handoff errors, and a successful MD calculation with a subsequent unrecognized
TRJ format error. Adding that unloaded result to a scene also failed.

Additional repairs:

- Native SSH subprocesses explicitly disable multiplexing without changing user
  SSH configuration or replaying submissions. Seven SSH tests and two sequential
  read-only calls through the actual worker transport on a configured SSH host passed. Scientific
  jobs were not submitted for this connectivity check.
- Native preview and scene import recognize XYZ data in TRJ/LOG/OUT/ARC only when
  the frame contains valid elements and finite coordinates. Original extensions
  and all frames are preserved. Native runtime tests, browser regression, and an
  offscreen WKWebView using the actual Mol* viewer passed (two atoms/two frames).
- Missing, failed or timed-out viewer extraction stops xTB/CREST; only explicit
  successful null context permits whole-document fallback. Tests cover rejection
  and absence of job submission.
- Browser backend rejects missing/null topology templates before Metal loading.
  Five backend tests passed; incomplete zero-bond output is no longer synthesized.
- Browser Chemical Space cancellation reaches the fetch and child process.
  Large-input cancellation and closed-stdin tests prevent unhandled EPIPE from
  crashing the development server.
- Action journal flushes batches of at most 200, matching the native limit, so a
  bounded 400-entry burst is no longer silently truncated by the backend.

`python3 scripts/collect-diagnostics.py --output <new-directory>` captures bounded
local app/action logs without requiring the app UI. It keeps safe job identifiers,
operations and errors for correlation, omits molecular details, and redacts URLs,
credentials and local paths. Captures are private local files, not uploads.
Diagnostic captures remain local and ignored by Git. The existing app already
writes these journals; new source fixes still require app delivery.

The final focused Rust tests and Clippy passed. A broad formatter also reformatted
unrelated workspace crates; those formatting-only edits were restored after exact
comparison with rustfmt output from HEAD. Thus whole-workspace formatting is not
claimed as a clean baseline gate for the final patch. Changed Rust files were
formatted individually. No release installation was replaced.
