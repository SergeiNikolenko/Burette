## Дополнительные воспроизведённые дефекты

1. В recovery `PreviewExtension/Web/viewer.js:4045`, внутри
   `renderMolstarPresetPreview`, используется необъявленная `value`.
   Вызов функции из исходника с минимальным preview-контекстом получает
   `ReferenceError: value is not defined`. Это ломает preview пресетов, хотя
   syntax check проходит.
2. Повторный Auto идёт через generic provider (main viewer.js:4585;
   recovery viewer.js:4524), а не через Story adapter. Реальный Mol* probe:
   до применения 1 surroundings / 6 representations, после — 0 / 3.
3. В `molstar-story-presentation.mjs` анимированные snapshot исключены из
   адаптации, но generic восстановление подавлено для всех Auto Stories.
   Текущая docking fixture без таких шагов, общий контракт остаётся неполным.
