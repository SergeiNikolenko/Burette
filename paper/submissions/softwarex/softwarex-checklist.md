# SoftwareX submission checklist

Checked on 10 July 2026 against the current SoftwareX Guide for Authors and the
2026 Original Software Publication LaTeX template.

## Journal and article type

- [x] Target journal: SoftwareX.
- [x] Article type: Original Software Publication.
- [x] Journal fit: open-source research software and visualization/workflow
  infrastructure.
- [x] JOSS deferred because Burrete does not yet meet its six-month public
  development-history gate.

## Manuscript format

- [x] Uses elsarticle with the official SoftwareX preprint settings.
- [x] Contains the mandatory code-metadata table (C1--C8).
- [x] Contains all five required sections:
  Motivation and significance; Software description; Illustrative examples;
  Impact; Conclusions.
- [x] Fewer than 3,000 words.
- [x] Four figures, below the maximum of six.
- [x] Abstract is below 250 words.
- [x] Six keywords, within the 1--7 range.
- [x] Corresponding author, full affiliations, email, and ORCID are present.
- [x] CRediT, funding, competing-interest, data-availability, and generative-AI
  statements are present.

## Repository and software

- [x] Public GitHub repository.
- [x] Version pinned to v1.0.22.
- [x] Publication snapshot reserved as the non-release tag
  softwarex-v1.0.22.
- [x] MIT License.
- [x] Root README.md documents purpose, installation, and use.
- [x] Root LICENSE, LICENSE.txt, and Licence.txt are present to satisfy both
  spellings used in the current guide and template.
- [x] Source code is present in the repository's documented component
  directories, including apps/desktop/src, apps/desktop/src-tauri,
  PreviewExtension, and ios/BurreteMobile.
- [x] CITATION.cff matches v1.0.22 and the manuscript title.

## References and figures

- [x] Every in-text citation has a bibliography entry.
- [x] Every bibliography entry is cited in the manuscript.
- [x] DOI records were resolved through Crossref or DataCite.
- [x] Web-only software references use official project pages.
- [x] Figures are author-generated screenshots or a deterministic Graphviz
  diagram; no third-party artwork is included.
- [x] Figure files are supplied separately at publication resolution.
- [x] Highlights file contains four bullets of at most 85 characters each.
- [x] Graphical abstract is supplied as a separate PNG.

## Upload package

- [x] Compile the final PDF without errors.
- [x] Visually inspect every PDF page.
- [x] Build, unpack, and independently compile the LaTeX source ZIP.
- [ ] Upload the manuscript PDF and source ZIP to Editorial Manager.
- [ ] Complete the submission through the ORCID-linked author account.
- [ ] Record the manuscript number and confirmation email.

## Open-access charge

SoftwareX is fully open access. The journal currently lists an article
publishing charge of USD 1,560, excluding taxes, payable only if the manuscript
is accepted. The author has authorized the submission.
